# HTMX documentation map

Use documentation for the HTMX version pinned by the application.

- [HTMX documentation](https://htmx.org/docs/)
- [HTMX reference](https://htmx.org/reference/)
- [HTMX events](https://htmx.org/events/)
- [HTMX server examples](https://htmx.org/server-examples/)
- [HTMX request headers](https://htmx.org/reference/#request_headers)
- [`HX-Trigger` response header](https://htmx.org/headers/hx-trigger/)
- [`hx-swap-oob`](https://htmx.org/attributes/hx-swap-oob/)

Confirm extension APIs against the installed major version; HTMX 1.x and 2.x
do not have identical extension packaging and migration behavior.

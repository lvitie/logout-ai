# Blender Python documentation map

Use the API documentation that matches the project's Blender version.

- [Current Blender Python API](https://docs.blender.org/api/current/)
- [Operator context gotchas](https://docs.blender.org/api/current/info_gotchas_operators.html)
- [Python threading limitations](https://docs.blender.org/api/current/info_gotchas_threading.html)
- [Command-line arguments](https://docs.blender.org/manual/en/latest/advanced/command_line/arguments.html)

release.

# Go web documentation map

Use documentation matching the Go version declared by the module.

- [`net/http`](https://pkg.go.dev/net/http)
- [`net/http/httptest`](https://pkg.go.dev/net/http/httptest)
- [`html/template`](https://pkg.go.dev/html/template)
- [`context`](https://pkg.go.dev/context)
- [Go race detector](https://go.dev/doc/articles/race_detector)
- [Go security best practices](https://go.dev/doc/security/best-practices)
- [Go vulnerability management](https://go.dev/doc/security/)

Prefer the standard library and the repository's existing dependencies before
adding a router, middleware package, or server abstraction.
